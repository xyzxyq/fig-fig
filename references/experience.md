# 制图经验

这些经验来自实际学术插图的反复制作与修订，已整理为可迁移的判断原则。它们不是统一审美标准；本次用户指令和用户指定参考始终优先。公开版本只保留通用经验，不附带私人对话、研究项目细节或工作文件。

## 可复用结论

1. **先保住科学内容，再改变视觉。** 用户可能认可内容/结构而否定画风；“保留这一版”也可能只是要求备份。明确冻结已认可的内容，保留用户指定无需改动的组件。
2. **抽象必须能解释机制。** 图形应让读者看懂对象、作用关系和结果。用具体对象间的对比、对应或进展表达机制；不以无含义色带、公式堆叠和通用图标替代解释。
3. **整篇论文使用一致的视觉语言。** 字体、组件、语义颜色、轮廓和箭头应跨图一致。具体参考图比“学术风格”标签更能约束制作；某一局部的颜色和字体不是永久默认。
4. **清楚、精致，并在缩印后可读。** 放大有效图标与关键标签，精简冗余小字，修顺连线。避免对比过低、轮廓朦胧、过度装饰或草率的组件；适度立体感不能损害辨认。
5. **原生结构与局部图像配合。** 全矢量不自动等于高质量。文字、箭头和框架保持原生可编辑；复杂科学组件可以用内置生图制作。适用的已认可素材可以沿用，不合适的素材按用户要求重画。

## 有效表达与失败模式

下面是匿名化的设计模式，用于帮助选方案；不代表某个研究方法的真实实现或实验结果。

| 场景 | 有效做法 | 常见失败 |
|---|---|---|
| 两个相邻模块含义不同 | 改变图中有意义的对象、操作或关系，让差异可见 | 两张相同图标换标题，造成冗余 |
| 展示对象间的相对变化 | 明确同一主体、多个比较对象，以及逐项对应的变化；数值示意需标明 | 只放抽象色块，或让示意条长看起来像真实排名 |
| 区分同类表示 | 保留角色身份色，用有图例的纹理或形状区分；融合只包括实际输入 | 多个相同彩虹条没有归属，或纹理暗示额外输入 |
| 表示简单比较或监督 | 直接展示两端对象、比较动作和结果；允许适当留白 | 为填满空间增加不相关图标、重复公式和复杂装饰 |
| 反复修改仍被否定 | 恢复上一版本，重新说明机制，用已认可局部校准表达 | 将技术合理性当成视觉满意度，继续润色已被拒绝的方案 |

## 优先解决的问题

1. **科学暗示错误。** 多对多被画成一一对应；融合被画成相加；更新记录被画成即时更新模型；软引导被画成硬约束。先校正含义再美化。
2. **箭头失控。** 汇合点不明、转角生硬、箭头头部歪斜、穿框压字、反馈与主流程混在一起。检查整条路径，不只修改箭头终点。
3. **尺度失衡。** 文字太多、图标太小、模块拥挤与大块空白并存。先回收冗余内容，再调整层级和尺寸。
4. **组件不匹配。** 视角、轮廓、阴影方向或材质不统一；重生成的科学对象与上下文身份不同。使用同一参考，并逐项核对。
5. **验收证据不足。** 文件成功保存、节点数量多或高清导出都不能证明科学正确、排版美观或印刷可读。检查实际截图和物理尺寸校样。

## 不应固定化的偏好

| 维度 | 判断原则 |
|---|---|
| 饱和度 | 参考本轮图像及语义配色；不把“学术”一概解释为低饱和 |
| 字体 | 遵循当前要求与参考，保留粗细层级；字体不可用时说明，不静默替换指定字体 |
| 平面与立体 | 可用克制的立体科学组件；不强制全扁平，也不追求摄影效果 |
| 留白与细节 | 空间服务于机制表达；既不一律填满，也不一律极简 |
| 保留与重绘 | 按当前选定对象和修改范围处理；一次局部重绘要求不授权全图重做 |

## 如何继续积累经验

区分四类反馈：喜欢某个参考风格、认可内容结构、认可局部表达、整图最终验收。只有用户明确选择或反复一致的反馈才能形成偏好；助手自评、技术检查通过和用户未回复都不能代替认可。

把新反馈的适用范围记录在当前图的本地状态文件。公开分享时保留可复用原则，移除私人会话标识、未公开研究材料和本机路径。
