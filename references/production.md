# Figma 制作与验收

进入 Figma 复现或精修阶段时阅读。这里规定成图质量与易错点，具体 API 以当前插件技能和工具 schema 为准。

## 插件操作

| 环节 | 操作要点 |
|---|---|
| 建立上下文 | 发现 Figma 工具；已有 fileKey 后按当前要求建立 `create_session`，同一任务复用返回的 sessionId。先读目标页和图框，不能仅凭页面序号或旧缓存选择目标。 |
| 原生编辑 | 使用 `use_figma`；事先读取 `figma-use` 及适用参考。完整多分区图按插件要求加载布局技能。此处“科学组件”不强制成为发布的 Figma 组件库。 |
| 文字与页面 | 先检查可用字体并加载后再改字；保持粗细层级。每次调用按插件要求切换目标页，不能假设上次页面上下文还在。 |
| 素材 | 本地/生成图像用工具支持的上传途径嵌入，保留原素材；SVG 是否原生可编辑、字体是否转轮廓都需实际检查。不要用整个参考图作为最终内容层。 |
| 恢复与状态 | 每次写入返回受影响节点 ID 与必要边界/数量；按错误返回的安全重试信息恢复。结果不明时先读画布，避免重建重复节点。状态存于本地，不依赖未支持的插件方法。 |

如果需要操作的是现有页面，缺少编辑权限或连接失败时，准确说明已完成的本地准备与未写入部分；不要绕到另一个文件假称完成原页修改。

## 原生对象与图像素材的分工

| 内容 | 优先实现 | 验收重点 |
|---|---|---|
| 标题、标签、公式 | 原生文字与可编辑数学排版 | 文字可单独改；下标、上标、希腊字母与粗体正确；正文语言一致 |
| 分区、容器、网络、特征条、箭头 | Figma 原生形状/矢量 | 可编辑、分组清楚、统一线宽和尺寸；不靠无语义装饰传达机制 |
| 复杂科学插画 | 已认可素材；必要时内置生图的独立高清组件 | 风格匹配、轮廓清楚、无裁边、无白色方块；不宣称其中原子/键经科学验证 |
| 指定分子、晶体或真实实验/模拟结果 | 用户提供或可追溯的科学绘图资产 | 身份、键连、单位、条件、来源准确；生图只用于不改变证据的视觉构思 |
| 真实数据曲线、柱图、统计区间 | 由真实数据用标准绘图工具产生的矢量图 | 不用生成式像素推断/重画数值；轴、单位、误差、图例与数据一致 |

可以采用“原生文字和结构 + 局部位图科学插画”的混合方式。只要含位图，就不能称“全矢量”；文字被转路径时也不能称“全部文字可编辑”。精美不是要求所有对象逐像素矢量化。

生图组件提示词只负责该组件的对象、视角、材质、配色、边界和透明背景，不把原图的小字、箭头与整张布局烘焙进去。优先与上下文同样的镜头角度、阴影方向和轮廓强度。微弱阴影可以加强节点层次；雾化、强光晕和摄影景深通常损害论文缩印后的辨认度。

## 排版与连线

1. **先查箭头语义，再查造型。** 记录源、目标、方向及关系；多对多关系不能被位置和颜色画成一对一。只有语义允许时才合并输入或共享条件模块。
2. **保持路由连续。** 转弯圆滑，拐角半径一致；箭头头部沿终点切线，不能侧歪、脱节、穿框或压字。多路合并有清晰汇合点；反馈线路与主流程可区分。
3. **控制层级。** 同级模块居中、对齐、间距一致；图标按视觉大小校准，不能只让外接矩形相同。字号和粗体层级匹配参考。数学符号不是小字装饰。
4. **整体与局部一起调整。** 放大拥挤模块前先回收重复内容与无效留白；删掉模块后重新平衡布局，不能只留下空洞。需要不同图形表达不同层级时，先改变有意义的对象或关系，再改变颜色。
5. **语义颜色和纹理。** 颜色标识角色或来源，不能每个标题都另设彩条。改变明度提高辨识度时保留已有身份。两种模态可用不同纹理区分，融合图只包含实际存在的输入，不凭视觉效果画出额外模态。

## 五项验收

| 检查项 | 必须得到的证据 | 不足以证明通过的情况 |
|---|---|---|
| 科学关系 | 对照有效材料检查输入输出、角色、融合/相加、监督、冻结与更新、引导/约束 | “看起来像机制图”；生成器自动画出的连线 |
| 编辑范围与对象 | 目标页面/图框、关键原生文字、素材与备份可定位；受保护内容对照无意外变化 | 节点数量多；整张图片放在可编辑画板里 |
| 视觉 | 看过实际 Figma 整图截图及必要的局部截图；无重叠、遮挡、截断、箭头连接问题 | 代码成功；几何检查无越界；只检查 SVG XML |
| 导出 | 实际打开 PNG/SVG/PDF；检查文本、透明素材、尺寸和渲染 | 工具返回一个未保存的下载链接；本地只有脚本 |
| 论文尺寸 | 按最终物理宽度看校样，检查最小文字、公式、细线、纹理与局部位图有效分辨率 | 只看放大后的 Figma 画布；高清 PNG；“300 dpi”文件标签 |

对同一版本的一次通过截图可以复用，未发生相关修改就不重复截图。自动几何检查可辅助发现越界，但不能证明排版美观。只做局部修订时，检查局部及邻接影响即可；不要声称完成未执行的整图科学复核或印刷验收。

### 物理尺寸换算

先确定目标宽度；没有明确期刊规格时可声明一个校样宽度假设，但不能据此宣布满足投稿标准。

若画板宽 `W_px`，排版宽 `W_mm`，某字号为 `f_px`：

```text
印刷字号（pt） = f_px × (W_mm / W_px) × 72 / 25.4
局部位图有效 dpi = 该位图实际使用的像素宽 / (其在论文中的宽度 mm / 25.4)
```

例如，宽 1672、字号 14 的画板缩至 180 mm，普通标签只有约 **4.27 pt**；即使 PNG 很清晰，文字仍然过小。修正应是精简、放大或分图，而非仅提高导出倍数。位图在 SVG/PDF 里也不会自动变成矢量或获得更多细节。

没有期刊专属要求时，可以先把普通标签约 7–9 pt 当作设计起点并做实际校样；这不是任何期刊的统一规定。需要声称符合某一期刊时，查该刊当前官方要求，再逐项核对。

## 最简交付记录

复用项目已有命名和目录；没有时在一个图的工作目录保留参考/获准稿、实际用到的素材、最终导出和一份状态记录。状态只需包含：

- 用户参考的出处、选定示意稿的版本、确认原话或对应消息，以及确认的是内容、风格还是整图。
- Figma file/page/frame ID 与直接链接；当前工作对象和可恢复的上一版本。
- 可编辑与位图部分、素材来源；哪些图形只是概念示意。
- 目标物理尺寸、实际检查结果、最终文件路径与未验证事项。

文件写入后确认存在与格式可读。不用导出校验代替目标应用外观检查，也不把在线 Figma 的修改误当成本地旧脚本已经同步。
